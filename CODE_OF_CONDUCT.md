# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, and inclusive environment for everyone.

## Expected Behavior

All contributors should:

- Be respectful and polite.
- Use welcoming and inclusive language.
- Accept constructive feedback.
- Respect different opinions and experiences.
- Focus on helping the project succeed.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or discrimination.
- Offensive or inappropriate comments.
- Personal attacks.
- Sharing private information without permission.
- Any behavior that makes others feel unsafe or unwelcome.

## Reporting Issues

If you experience or observe unacceptable behavior, please contact the repository maintainer through GitHub Issues.

**Contact:** Repository Maintainer — GitHub Issues

## Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.

## Scope

This Code of Conduct applies to all activities related to this repository, including issues, pull requests, discussions, and wiki contributions.
